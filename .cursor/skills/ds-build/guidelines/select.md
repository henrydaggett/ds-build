# DsSelect guidelines

## When to use

- Use a DsSelect to choose one option from a list of about four or more.
- Use a DsToggleGroup for two or three options that should all be visible.
- Use a DsCheckboxGroup when more than one option can be chosen.

## Content

- Always give the select a visible label with a DsField, unless it sits in a toolbar.
- Use a placeholder that prompts the choice: "Select a country".
- Keep option labels short and order them logically (alphabetical, by size, or by frequency).
- Only preselect an option when there's a sensible default.

## Layout

- Selects fill their container, like DsTextInput.
- Use the same size as the inputs around it.
