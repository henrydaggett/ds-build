# DsTextInput guidelines

## When to use

- Use a DsTextInput for short, single-line text: names, emails, search terms.
- Use a DsSelect when the answer is one of a fixed list.

## Content

- Always give the input a visible label with a DsField, except for search bars.
- Use the placeholder for an example value, not for the label or instructions.
- Put instructions in the DsField description instead of the placeholder.
- Use the matching type for email, password, phone, URL and number inputs.

## Layout

- Inputs fill their container, so let the form or layout set the width.
- Use the same size for all inputs in a form.
- Match input size to the buttons next to it.
