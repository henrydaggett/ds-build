# DsForm guidelines

## When to use

- Use a DsForm when the input has fields and a submit action, like sign up, log in or checkout.
- Don't use a DsForm for a single search box or settings that apply immediately.

## Content

- Only include the fields the input asks for.
- Mark mandatory fields required and give them an error message.
- Label the submit button with what it does: "Create account", not "Submit".

## Layout

- Order fields in the order the input shows, or the order people expect (name before email).
- Use Fieldsets for long forms with distinct sections.
- Put all buttons in one DsFormActions as the last item.
- Put the primary submit button first, followed by Cancel or Back.
- Right-align buttons only when the input shows them on the right.
- Keep one column; don't place fields side by side.
