# Typography guidelines

## When to use

- Use typography classes for headings and text that sit outside components.
- Don't use them to restyle component text, like DsButton labels or DsField labels.
- Use `ds-text-medium` for most body text.
- Use `ds-text-large` for a short intro under a page title.
- Use `ds-text-small` for captions, meta text and footnotes.

## Content

- Use one `ds-h1` per page, for the page title.
- Don't skip heading levels: an `h3` follows an `h2`, not an `h1`.
- Use sentence case for headings.
- Keep headings short and don't end them with a full stop.
- Keep paragraphs short; split long text into several `p` elements.

## Layout

- Put the space below a heading smaller than the space above it, so the heading sits with its content.
- Use `ds-mb-8` between a heading and its text.
- Use `ds-mb-24` or `ds-mb-32` between sections.
