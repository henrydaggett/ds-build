# DsCheckbox guidelines

## When to use

- Use a single DsCheckbox for one yes/no choice, like "Remember me" or accepting terms.
- Use a DsCheckboxGroup for several related options under one heading.
- Use a DsToggle for settings that apply immediately.

## Content

- Write labels as positive statements: "Send me updates", not "Don't send me updates".
- Keep labels short and in sentence case.
- Use indeterminate only for a "select all" checkbox when some items are selected.

## Layout

- A single checkbox doesn't need a DsField unless it shows helper text or an error.
- Leave checkboxes unticked by default unless the input shows them ticked.
- Place a terms checkbox just above the form's buttons.
