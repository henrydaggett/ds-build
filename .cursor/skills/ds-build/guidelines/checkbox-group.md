# DsCheckboxGroup guidelines

## When to use

- Use a DsCheckboxGroup when the user can choose any number of related options.
- Use a DsSelect or single-choice DsToggleGroup when only one option can be chosen.

## Content

- Give the group a label that names the question: "Notifications", "Interests".
- Keep option labels short and parallel.
- Use the description for guidance like "Choose up to three".
- Order options logically, most common first.

## Layout

- Use vertical orientation by default; it's easiest to scan.
- Use horizontal orientation only for short labels, like days of the week.
- Keep groups to about seven options or fewer.
- Don't wrap a DsCheckboxGroup in a DsField.
