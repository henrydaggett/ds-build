# DsToggle guidelines

## When to use

- Use a DsToggle for a setting that turns on or off and applies immediately, like Bold or Wrap text.
- Use a DsButton for actions.
- Use a DsCheckbox for a choice that's saved when a form is submitted.
- Use a DsToggleGroup when several toggles control related options.

## Content

- Keep labels to one or two words that name the setting: "Bold", "Grid view".
- Don't change the label between pressed and unpressed.
- Use icon-only toggles only for well-known icons, like bold or alignment.

## Layout

- Group related standalone toggles in a row.
- Use the same size for toggles that sit next to each other.
- Show the pressed state only for settings that are on in the input.
