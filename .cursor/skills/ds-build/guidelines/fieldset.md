# DsFieldset guidelines

## When to use

- Use a DsFieldset to split a longer form into titled sections, like "Billing details" and "Shipping address".
- Don't use a DsFieldset for a short form with a single group of fields.
- Don't use a DsFieldset just to title one DsCheckboxGroup; use the group's label.

## Content

- Keep legends short nouns that name the section.
- Use the description for one line of context about the section.

## Layout

- Place Fieldsets directly inside a DsForm, one after another.
- Don't nest Fieldsets.
- Keep buttons outside Fieldsets, in DsFormActions at the end of the DsForm.
